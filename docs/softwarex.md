# SoftwareX readiness

This checkout is a software distribution prepared for reproducibility review,
not a completed publication artifact. It remains explicitly unreleased: no tag,
GitHub release, DOI, or Zenodo deposit is claimed by this checkout.

## Availability

Source code, experiment configuration, test scripts, deployment manifests, and
the Apache-2.0 license are in this repository. Training is offline. Live
inference uses a frozen model bundle, and model bundles plus large measured data
are expected to be supplied as release artifacts when they pass validation; they
are not implied by the presence of configuration files. A future release may
deposit raw traces, validated summaries, model bundles, plots, and version
capture in Zenodo.

## Evidence policy

Configuration checks, tests, YAML validation, and the reproduction dry run are
available now. They establish implementation and contract status. Measured
performance tables use a complete run matrix, explicit seeds, recorded
environment, cross-cluster replica migration invariant checks, and a successful
artifact-validator report.

## Illustrative output

SoftwareX readers can inspect the output format without running the measured
campaign:

```bash
python3 experiments/softwarex_reproduction.py \
  --config experiments/config/softwarex_reproduction.yaml \
  --stage all --dry-run --run-id dry-run
```

The command writes `results/softwarex-reproduction/dry-run/compact_results.csv`.
That file is intentionally marked `validation_status=dry-run-unvalidated` and
demonstrates the sample table shape.

Measured CSVs are generated by:

```bash
python3 experiments/generate_paper_artifacts.py \
  --results-root results/softwarex \
  --output-dir results/softwarex/artifacts
```

This command uses the repository artifact validator before writing
`main_comparison.csv` and related measured tables. Use it with measured bundles
that pass validation.

Known limitations include dependence on a Karmada/Kind testbed, Prometheus and
Istio metric availability, immutable bundle compatibility, and the need for a
dedicated measurement host for the full measured matrix. These limitations do
not affect the dry-run contract; they define the environment for measured
artifacts.
